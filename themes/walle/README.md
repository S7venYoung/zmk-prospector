# WALL-E / Codex

Industrial yellow-and-charcoal Prospector receiver theme designed for the rotated 280x240
Waveshare display. Foreground content respects the panel's approximately 43-pixel rounded-corner
safe area.

Select it by adding `prospector_theme_walle` to the receiver's shield list.

Theme-local fonts, images, icons, and future configuration belong in this directory.
